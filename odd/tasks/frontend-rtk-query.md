# Frontend RTK Query Migration

## Overview
Implemented an RTK Query `apiSlice` in **frontend/src/features/api/apiSlice.ts** with the following endpoints:
- `getMeters`
- `getMeterDetail`
- `getAnalysis`
- `getMeterReadings`
- `getMeterAnomalies`

The slice exports corresponding React hooks for easy consumption in components.
